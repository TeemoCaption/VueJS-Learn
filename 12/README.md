# Vue 插件（Plugin）學習筆記

## 一、插件是什麼？

插件是把「需要在整個 Vue 應用程式共用」的功能封裝起來，並在應用程式啟動時一次安裝。

```js
app.use(MyPlugin)
```

`app.use()` 會執行插件的 `install(app, options)`，因此插件的初始化工作會集中在 `install()` 中完成。

## 二、插件可以做什麼？

插件常見的用途包括：

- 註冊全域元件：`app.component()`
- 註冊全域自訂指令：`app.directive()`
- 建立全域屬性或工具：`app.config.globalProperties`
- 提供全域依賴：`app.provide()`，讓後代元件使用 `inject()` 取得

所以插件本身不是新的功能種類，而是把多個全域初始化工作組合成一個可重複安裝的模組。

## 三、插件的基本流程

```text
建立 Vue 應用程式
      ↓
app.use(插件, 設定)
      ↓
install(app, 設定)
      ↓
註冊全域功能或提供共用資源
```

插件也可以接收設定，例如網址或其他選項，讓同一個插件能依不同專案需求調整行為。

## 四、目前範例的重點

本單元的 `main.js` 使用 `app.use()` 安裝兩個插件：

- `helloPlugin`：示範插件安裝時執行初始化工作。
- `formatPlugin`：透過 `app.config.globalProperties` 提供全域 `$upper()` 工具。

元件只要在插件安裝完成後，就能使用插件提供的功能，不必在每個元件重複設定。

## 五、插件與組合式函式的差異

| 比較 | 插件 | 組合式函式 |
|---|---|---|
| 使用方式 | `app.use()` | `useSomething()` |
| 作用範圍 | 整個應用程式 | 使用它的元件或函式 |
| 執行時機 | 應用程式啟動時 | 元件執行邏輯時 |
| 主要目的 | 建立全域能力與初始化 | 重複使用元件邏輯 |

判斷方式很簡單：

- 只有少數元件需要的邏輯，優先使用組合式函式。
- 多個元件都需要的全域資源或初始化，才考慮插件。

## 六、常見錯誤

- 忘記執行 `app.use()`，導致插件的 `install()` 根本沒有被呼叫。
- 把只供單一元件使用的功能做成全域插件，增加依賴與維護難度。
- 全域屬性名稱過於普通，造成命名衝突；通常會使用 `$` 作為辨識前綴。
- 以為插件只能提供全域函式；實際上也能註冊元件、指令，或透過依賴注入共享設定。

## 七、核心觀念

> 插件的核心不是「把程式碼放到全域」，而是將應用程式啟動時需要完成的共用設定集中管理。

Vue Router、Pinia 等套件也透過 `app.use()` 安裝，本質上都是利用插件機制完成初始化與共享資源。
